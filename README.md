# 📱 Bay Kifer - Mobil Geliştirme Programı

## 🎯 Proje Açıklaması
**Bay Kifer**, mobil uygulama geliştirme konusunda becerilerimi göstermek için oluşturduğum bir kişisel portfolio projesidir.

## 📌 Proje Detayları
- **Proje Adı**: Bay Kifer
- **Proje Türü**: Mobil Uygulama
- **Ana Amaç**: Kişisel Portfolio
- **Açıklama**: Mobil geliştirme programı

## 🚀 Özellikler
- Modern mobil uygulama mimarisi
- Kullanıcı dostu arayüz
- Verimli ve hızlı performans
- Responsive tasarım

## 💻 Teknolojiler
Projede kullanılan teknolojiler:
- JavaScript / TypeScript
- React Native
- Mobile Development Tools
- Git & GitHub

## 📚 Kurulum
```bash
# Depoyu klonlayın
git clone https://github.com/Kiferbay/Kifer-Bay-.git

# Proje dizinine gidin
cd Kifer-Bay-

# Gerekli paketleri yükleyin
npm install
```

## 🛠️ Kullanım
```bash
# Geliştirme sunucusunu başlatın
npm start

# Uygulamayı derleyin
npm run build
```
